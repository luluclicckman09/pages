Privacy policy

Last updated: 2026-11-06

Secretary Bot is a private application used only by its developer, on the developer's own computer. It has no other users and no server of its own.

What it accesses

  • Google Calendar: events, read and edited at the owner's request.
  • Google Tasks: tasks, read and edited at the owner's request.
  • Gmail: messages are read, and drafts are prepared. The app never sends mail.

How the data is used

Data is used only to give the owner the assistant's answers (agendas, reminders, summaries, drafts). It is not sold, shared, used for advertising, or used to train any model. Content may be sent to an AI model (Anthropic's Claude API) only to answer the owner's own request.

Storage

Data stays on the owner's computer. Sign-in tokens are kept in the Windows Credential Manager. Nothing is stored on any third-party server run by the developer.

Deletion

The owner can revoke access at any time at myaccount.google.com/permissions and can delete the local data from the computer.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
